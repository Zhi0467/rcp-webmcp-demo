# Search-assisted plasticity study

This is the authoritative repository for the public challenge project's small
synthetic study. It asks whether a search-assisted value learner retains more
ability to learn after a second task shift than a value-only learner does.

The durable RCP graph records the question, the governing matching decision,
the Experiment ledger, and the limits on interpretation. The checked-in
`study/` directory contains the held-out table and a standard-library reference
analysis, so a real provider can inspect and reproduce every number it reports.

The values are intentionally synthetic. They make the public demonstration
reproducible and safe to host; they are not measurements from the private CRLP
project and should not be generalized beyond this fixture.
